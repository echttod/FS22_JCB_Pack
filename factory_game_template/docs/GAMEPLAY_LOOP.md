Gameplay Loop (Template)
========================

Ziel: Spieler baut eine Fabrik, die Rohstoffe automatisiert verarbeitet.

1) Explore
   - Resource Nodes finden und markieren.

2) Build
   - Extractor/Conveyor/Smelter/Storage platzieren.
   - Layout optimieren.

3) Automate
   - Items bewegen und verarbeiten.
   - Outputs in Storage sammeln.

4) Expand
   - Neue Tech-Stufen, effizientere Maschinen, groessere Fabrik.

Hinweis:
Dieses Dokument ist ein Startpunkt fuer das Design. Ergaenze
Produktionsketten, Rezepte, Stromversorgung und Progression.
