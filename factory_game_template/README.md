Factory Game Template (Satisfactory-like)
=========================================

Dieses Template ist ein kompletter Startpunkt fuer ein First-Person
Fabrikgame mit sichtbaren Haenden. Es ist als Godot-4-Projekt aufgebaut
und enthaelt die wichtigsten Systemskelette, damit du sofort iterieren
kannst.

Features (Template-Stand)
-------------------------
- First-Person Controller mit sichtbaren Haenden (Viewmodel).
- Build-Mode mit Ghost-Preview, Grid-Snap und Rotation.
- Beispiel-Buildables: Conveyor, Smelter, Storage.
- Resource Node als interaktives Objekt.
- Einfaches HUD mit Status und Controls.

Quick Start
-----------
1. Godot 4.x starten.
2. Project oeffnen: `factory_game_template/project.godot`
3. Main Scene starten (Play).

Controls (Default)
------------------
- WASD: Laufen
- Maus: Blicken
- Space: Springen
- Shift: Sprinten
- F: Interagieren
- B: Build-Mode an/aus
- Q/E: Buildable wechseln
- Z/C: Buildable drehen
- Linke Maustaste: Platzieren
- Esc: Maus freigeben

Projektstruktur
---------------
- `scenes/`: Haupt- und Teilscenes
- `scripts/`: Gameplay-Skripte
- `docs/`: Design- und Setup-Hinweise
