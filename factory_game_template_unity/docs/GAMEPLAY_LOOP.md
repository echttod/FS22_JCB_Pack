Gameplay Loop (Template)
========================

1) Explore
   - Resource Nodes finden und markieren.

2) Build
   - Extractor/Conveyor/Smelter/Storage platzieren.
   - Layout optimieren.

3) Automate
   - Items bewegen und verarbeiten.
   - Outputs in Storage sammeln.

4) Expand
   - Neue Tech-Stufen, effizientere Maschinen, groessere Fabrik.

Hinweis:
Dies ist ein Startpunkt. Ergaenze Rezepte, Stromversorgung,
Logistik und Progression.
